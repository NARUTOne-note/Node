IP、MAC 和虚拟地址，一次讲明白

用寄快递的方式，看懂电脑、服务器、虚拟机身上的各种地址。

详细文字版：ip-mac-address-basics.md

先记住：一次通信要用三层地址

网络通信像寄快递：先按地址找到楼，再按房间号找到人。计算机网络里，“楼”是 IP，“房间号”是端口，“收件人的身份证”是 MAC。

MAC 地址：网卡的身份证

  • 全名 物理地址 / 硬件地址，一台设备有几块网卡就有几个 MAC。
  • 写法是 6 组十六进制数，例如 00:1A:2B:3C:4D:5E。
  • 数据在同一个局域网里转发时，靠 MAC 找网卡；交换机就是按 MAC 转发的。
  • 系统要发数据前，会先用 ARP 问一句：“这个 IP 是哪块网卡的？”从而拿到 MAC。
  • 默认出厂固定，但软件可以伪装（改 MAC），所以它不能当密码用。
MAC 只在“同一条局域网”里有意义。数据每经过一个路由器，外层会被换成下一段的 MAC，但 IP 一般保持不变。

IP 地址：网络里的门牌号

  • IPv4 是 32 位，写成 4 段十进制数，每段 0–255，例如 192.168.1.10。
  • IP 是逻辑地址：换一个网络（换 Wi-Fi、换机房），IP 就可能变。
  • 常看到的 192.168.1.10/24，/24 就是子网掩码的简写，表示前 24 位是网络部分。
  • IPv6 是 128 位，用十六进制和冒号表示，地址多到几乎用不完，以后会慢慢替代 IPv4。

同小区直接喊，跨小区找门卫

每台电脑都配了一个默认网关，通常就是家里/公司的路由器。发数据前先比一下网段：对得上，直接喊；对不上，全部交给网关。

内网 IP 和公网 IP，为什么要分开

  • 内网 IP（私有地址）只能在家里/公司内部用，常见 192.168.x.x、10.x.x.x、172.16–31.x.x。
  • 公网 IP 是全球唯一的，运营商分配。公网 IP 很紧张，所以一个家庭通常只分一个。
  • NAT 是路由器干的事：出门时把“内网 IP + 端口”改写成“公网 IP + 另一个端口”，回来时再改回去。
  • 正因为 NAT，外网默认无法主动连进来。想让自己电脑被访问，需要端口映射（内网穿透）或云服务器。
你查到的“我的 IP”经常是 192.168 开头，那只代表你在局域网里的位置；别人看到的是你家路由器的公网 IP。

服务器上的 IP 是怎么回事

你输入网址后，浏览器先问 DNS：“这个名字对应哪个 IP？”拿到 IP 才真正发请求。服务器本身可以同时拥有好几个地址：

  • 公网 IP：给全世界访问的入口。云厂商常叫“弹性公网 IP / EIP”，背后其实是 NAT 映射到内网 IP。
  • 内网 IP：同一台机器在机房/VPC 里的地址，数据库、内部服务之间用它通信，更安全也更快。
  • 127.0.0.1：回环地址，永远指向自己，不经过网卡。程序里写 localhost 就是连它。
  • 0.0.0.0：不是一个能被访问的地址，而是“监听所有网卡”的写法。服务监听 0.0.0.0:80，外网和内网才能连进来；只写 127.0.0.1 则只有本机能连。
  • 端口决定找哪个程序：网站 80/443、SSH 22、MySQL 3306。
云服务器连不上？顺序检查：服务是否监听 0.0.0.0 → 本机防火墙 → 云厂商安全组 → 公网 IP 是否绑对。

“虚拟地址”到底指什么？

这个词在不同场景意思不一样，听到时先看上下文。网络上常说的是下面三种，最后一种其实是内存，容易混淆。

1. 回环地址：自己发给自己

127.0.0.1 是操作系统内部的虚拟接口。数据根本不离开本机，写得快、不依赖网络，开发时常用它测试本地服务。

2. 虚拟机 / 容器的地址：软件造出来的网卡

虚拟机、Docker、K8s 都会创建“虚拟网卡”和“虚拟交换机”，再给里面的系统分配 IP。这些 IP 只在那套虚拟网络里有意义。

虚拟机网络模式IP 从哪来谁能访问
桥接和宿主机同一个局域网，由路由器分配局域网内其他设备都能访问
NAT虚拟机软件自己分配（常见 192.168.x.x）虚拟机能出去，外面进不来（要端口映射）
仅主机虚拟机软件自己分配只有宿主机和虚拟机互通
Docker 默认docker0 网桥分配（常见 172.17.x.x）容器间互通，外部访问要 -p 映射

3. 虚拟 IP（VIP）：会漂移的地址

负载均衡器对外只暴露一个 IP，后面挂很多台服务器。某台挂了，地址自动飘到另一台上，用户感觉不到。K8s 的 Service ClusterIP 也是这种“虚”的地址。

4. 别混淆：内存里的“虚拟地址”

进程看到的 0x7ffd... 这类地址，是操作系统通过页表映射到物理内存的虚拟地址，和 IP、MAC 完全不是一回事。

常见疑问

为什么我的电脑 IP 是 192.168 开头？

那是私有地址，只在你所在的局域网里有效。互联网上别人看到的是路由器或运营商的公网 IP，不是你电脑的内网 IP。

为什么路由器重启后，电脑的 IP 变了？

因为路由器用 DHCP 自动分配地址，而且有“租期”。想固定的话，可以在路由器里做“MAC 绑定 IP”（DHCP 静态分配）。

服务器为什么既有公网 IP 又有内网 IP？

云厂商用 NAT 把公网 IP 映射到内网 IP。公网 IP 负责让外面访问进来，内网 IP 负责同一机房/VPC 内的高效、安全通信。

0.0.0.0 和 127.0.0.1 有什么区别？

127.0.0.1 只代表本机，服务写它就只有本机能连。0.0.0.0 是“监听所有网卡”的写法，服务写它，内网和外网（在防火墙允许的前提下）都能连。另外，0.0.0.0 出现在路由表里表示“默认路由”，那是另一个含义。

宿主机 ping 不通虚拟机，是什么原因？

先看虚拟机的网络模式：仅主机只能宿主机访问，NAT 一般宿主机能访问但外部不行，桥接才和局域网平级。再检查虚拟机内部防火墙和 IP 是否配在同一网段。

MAC 地址能改吗？

可以，操作系统和网卡驱动允许软件伪装 MAC。但它只是局域网转发用的标识，改了也不会让你变成另一台受信任的设备。

记住一句话

IP 负责找到机器，端口负责找到程序，MAC 负责在局域网里认网卡；内网地址出门要靠 NAT 换成公网地址，名字则要靠 DNS 翻译成 IP。
