Computer System Architecture

计算机的主要构成结构 · 多层嵌套

计算机系统 = 硬件子系统（主机 + 外设）+ 软件子系统（固件 + 操作系统 + 应用 + 数据）。主机内以主板为 backbone，插接 CPU / 内存 / 显卡 / 存储。

硬件的嵌套层级

  • • L1 计算机系统 ⊃ L2 硬件 ⊃ L3 主机 ⊃ L4 主板 ⊃ L5 元件
  • • 主机 = 机箱内：主板 + 电源 + 散热
  • • 主板是 backbone：CPU / 内存 / 显卡 / 存储 都插在它上面
  • • 显卡本身又内含 GPU 芯片 + 显存（再深一层）
  • • 外设在机箱外：显示器 / 键鼠 / 网络 / U盘

软件的嵌套层级

  • • L2 软件 ⊃ 固件(BIOS) ⊃ 操作系统 ⊃ 驱动 ⊃ 应用
  • • BIOS/UEFI：开机第一层，自检硬件
  • • OS：调度 CPU / 内存 / 磁盘，是软件总指挥
  • • 驱动：OS 与硬件之间的翻译官
  • • 应用 + 数据：最上层，通过 OS 间接用硬件

一次完整的数据流

  • • 1 输入：键鼠/网络 把指令送进主机
  • • 2 取数：硬盘档案 → 先搬进内存（CPU 才能用）
  • • 3 计算：CPU 在内存上算；要画图就交给 GPU
  • • 4 画图：GPU 用显存拼好画面
  • • 5 输出：显示信号经 HDMI/DP 送到显示器
  • • 软件全程经 OS/驱动 指挥这一切
