计算机硬件组件

一句话概括：电脑是一堆零件分工合作，把「算、记、连、看」各司其职拼起来。

电脑到底是什么？

把电脑想成一个「加工厂」：有人算数、有人搬货、有人画图、有人保管档案、有人对外展示。每个零件就是工厂里的一个工位。

挨个认零件

处理器 Processor

能「算数 + 做决定」的芯片的总称。CPU、GPU 都是处理器，只是分工不同。

像 会算账的人，谁能算、算什么不一样。

CPU 中央处理器

电脑的「总指挥」，什么都管：算数、判断、调度别的零件。核多就多人一起算。

像 工厂的总经理 + 大脑，慢但样样精通。

GPU 图形处理器

专干「同时算一大片」的活：画画面、渲染、AI。核心多但每个都简单。

像 画图车间里一大排小工，单挑不行、人多力量大。

显卡 Graphics Card

一块完整的板子，上面焊着 GPU 芯片 + 显存 + 供电，是「打包好的画图部门」。

像 整个画图部门，GPU 是里面的人、显存是他们的桌。

内存 RAM / 内存条

CPU 的临时工作台，放「正在用」的数据。断电就清空，要快。

像 办公桌，桌面越大能摊开的活越多，下班（关机）就收干净。

显存 VRAM

GPU 自己的临时工作台，专门放画面和纹理。和内存是两块独立的地方。

像 画图车间专用的画图桌，跟总经理的办公桌不通用。

主板 Motherboard

一块大板子，上面有插槽和「公路」（总线），把所有零件插上去连成一体。

像 工厂的走廊 + 电线，零件各就各位，靠它互通。

硬盘 Storage

长期仓库，放系统、照片、游戏。断电不丢，但要慢慢搬。

像 档案柜，存得多但拿东西要时间，得先搬到桌上（内存）才能用。

电源 PSU

把墙上电变成各零件要的电压，喂饱所有人。功率不够会重启。

像 供电站，给全厂供电，不够用就跳闸。

散热 Cooling

芯片算得快会发烫，散热（风扇/水冷）把热吹走，防止降频烧坏。

像 空调 + 排风扇，机器越忙越要吹凉。

显示器 Monitor

GPU 画好的画面送到这里，给你看。是「输出设备」，不参与计算。

像 工厂的展示橱窗，只摆成果、不生产。

机箱 Case

铁皮盒子，把主机里的零件装一起，挡灰、固定、走风道。

像 工厂的厂房外壳，不干活但保护里面的人。

容易混的关系

对比区别一句话
处理器 vs CPU处理器是「会算的芯片」总称；CPU 是其中当总指挥的那种。GPU 也是处理器。
CPU vs GPUCPU 少核、每个强、样样能干；GPU 多核、每个弱、专攻并行（画面/AI）。
显卡 vs GPU vs 显存显卡=整块板子；GPU=板上那颗算图芯片；显存=板上给 GPU 用的临时存储。三者是「部门/人/桌」关系。
内存 vs 显存内存（RAM）给 CPU 用；显存（VRAM）给 GPU 用。各管各的桌，互不通用。
内存 vs 硬盘内存是临时桌（快、断电清空）；硬盘是长期柜（慢、断电不丢）。先用必先从柜搬到桌。

记住一句话

电脑 = 主板当地基，上面插着 CPU（总指挥）+ 内存（它的桌）+ 显卡（含 GPU 和显存，画图部门）+ 硬盘（档案柜），电源喂饭、散热吹凉、机箱罩着、显示器给外面看。
