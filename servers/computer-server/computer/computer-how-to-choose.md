# 处理器、显卡、内存、硬盘怎么挑

> 一句话概括：先想清楚「拿电脑干什么」，再按用途给四个零件分配预算——游戏重显卡、干活重 CPU、多开重内存、体验重固态。

配套概念讲解见同目录 `computer-overview.md`。这份文档只讲「怎么选」。

---

## 总体原则

1. **先定用途，再定预算，最后挑零件。** 不同用途的预算分配完全不同，没有「全能水桶机」，只有「钱花在刀刃上」。
2. **短板决定体验。** 整机速度由最慢的那个零件决定，别让某一个零件拖后腿。
3. **买新不买旧，但不必追旗舰。** 甜点级（次旗舰往下两档）通常性价比最高。

### 按用途的预算分配参考

| 用途 | CPU | 显卡 | 内存 | 硬盘 |
|------|-----|------|------|------|
| 办公 / 上网 / 网课 | 入门即可 | 核显足够 | 16GB | 512GB SSD |
| 游戏（1080P） | 中端 | **中端~中高端（重头）** | 16~32GB | 1TB SSD |
| 游戏（2K / 4K） | 中高端 | **高端（绝对重头）** | 32GB | 1~2TB SSD |
| 编程 / 开发 | **中高端（重头）** | 核显或入门独显 | 32GB 起步 | 1TB SSD |
| 视频剪辑 / 渲染 | **高端（重头）** | 中高端（辅助加速） | 32~64GB | 2TB SSD + 大容量仓库盘 |
| AI / 深度学习 | 中高端 | **高端 N 卡（显存越大越好）** | 32~64GB | 2TB SSD |
| 家庭服务器 / NAS | 低功耗入门 | 核显即可 | 16~32GB | 系统 SSD + 大容量 HDD |

## 处理器 CPU 怎么挑

> CPU 是总指挥，决定「日常反应快不快、干活效率高不高」。

### 看哪些参数

- **核心数 / 线程数**：核心 = 干活的人。日常 6~8 核够用；多开虚拟机、编译、渲染越多核越好。
- **频率（GHz）**：每个核心算多快。游戏更吃单核频率，别只看核数。
- **缓存（L3）**：越大越好，游戏 CPU（如 AMD X3D 系列）靠大缓存明显提升帧数。
- **制程 / 代数**：买近一两代的产品，同价位性能更强、功耗更低。
- **接口 / 平台**：Intel 是 LGA1700 / LGA1851，AMD 是 AM4 / AM5。**先定 CPU 再选主板**，接口必须对上。AM4 已停产线，新装机优先 AM5 或 Intel 新平台。

### 常见误区

- ❌「i7 一定比 i5 好」—— 要同时看代数，新一代 i5 常打赢老 i7。
- ❌ 核数越多越好 —— 游戏只吃几个核，盲目堆核浪费钱。
- ✅ 不带 K / X 的型号性价比更高；不超频就别为超频功能买单（也不用买贵的 Z 系主板）。

### 快速结论

- 办公：当前代 i3 / R5 或带核显的入门型号。
- 游戏：当前代 i5 / R5（追求高帧率选 AMD X3D 系列）。
- 生产力 / 编译 / 渲染：i7 / R7 以上，核心越多越好。

## 显卡 GPU 怎么挑

> 显卡是画图部门，决定「游戏帧数高不高、AI/渲染跑不跑得动」。不打游戏、不跑 AI，可以不买独显。

### 看哪些参数

- **型号档位**：N 卡看 60/70/80（数字越大越强），A 卡同理。同代同档，性能差距有限，按预算选档。
- **显存 VRAM**：1080P 游戏 8GB 起步，2K 建议 12GB，4K / AI 训练 16GB 起步。**显存不够直接爆，核心再强也没用。**
- **功耗与供电**：高端卡动辄 300W+，电源和机箱散热要跟得上。
- **尺寸**：三风扇大卡很长，下单前量好机箱能放多长的卡。

### N 卡 vs A 卡

| 维度 | NVIDIA | AMD |
|------|--------|-----|
| 光追 / DLSS | 强 | 弱一些 |
| AI / CUDA 生态 | **几乎垄断，跑 AI 必选** | 生态弱 |
| 同价位光栅性能 | 略低 | 略高，性价比好 |
| 驱动稳定性 | 好 | 近年已不错 |

### 快速结论

- 只办公 / 看视频 / 写代码：**核显够用，省掉显卡钱**。
- 1080P 游戏：甜点级（60 档）。
- 2K 高刷：70 档。
- 4K / AI / 大模型：80 档以上 + 大显存，AI 只考虑 N 卡。
- 二手矿卡风险高，新手别碰来历不明的二手卡。

## 内存 RAM 怎么挑

> 内存是临时工作台，决定「能同时开多少东西不卡」。容量优先级 > 频率。

### 看哪些参数

- **容量**：2020 年代的标准答案 —— 办公 16GB，游戏 / 开发 32GB，剪辑 / 虚拟机 / AI 64GB 起步。**容量不够会卡死，频率低一点只是慢一点。**
- **代数**：DDR4 还是 DDR5 由主板决定，两者互不通用。新装机（AM5 / Intel 新平台）直接 DDR5。
- **频率与时序**：DDR5 甜点在 6000MHz 左右，再高提升小、价格陡增；时序（CL 值）越低越好，但优先级最低。
- **通道**：**买两根组双通道**（2×16GB 好于 1×32GB），带宽翻倍，核显性能尤其受益。想留升级空间可以插 2 根占 4 槽的一半。

### 快速结论

- 容量：16GB 起步，主流 32GB。
- 规格：新平台 DDR5-6000，两根套条组双通道。
- 品牌：金士顿、威刚、芝奇、英睿达等大牌皆可，兼容性比频率重要。

## 硬盘 Storage 怎么挑

> 硬盘是长期仓库，决定「开机、加载快不快、能存多少东西」。**现在装机的底线是全 SSD，HDD 只当仓库盘。**

### 看哪些参数

- **接口 / 协议**：
  - **NVMe SSD（M.2 插槽）**：主流之选，读速 3500~7400MB/s，系统盘必选。
  - **SATA SSD**：老机器升级用，500MB/s 左右，比机械盘仍快一个量级。
  - **HDD 机械盘**：只做照片 / 视频 / 备份仓库，便宜量大（4TB 几百块）。
- **容量**：系统盘 1TB 是甜点（512GB 很快就满）；仓库盘按需 2~4TB+。
- **PCIe 代数**：PCIe 3.0 / 4.0 / 5.0，日常体验差距很小，**4.0 是性价比甜点**，5.0 发热大、贵，普通用户不必追。
- **有无独立缓存（DRAM）**：有 DRAM 的盘持续读写更稳，适合当系统盘；无缓盘（HMB）便宜，当游戏盘 / 仓库盘够用。
- **颗粒类型**：TLC 主流首选；QLC 便宜但写入寿命和掉速明显，只配当仓库盘。

### 快速结论

- 系统 + 常用软件 / 游戏：1TB NVMe PCIe 4.0 带缓存 TLC 盘。
- 素材 / 备份仓库：2TB+ NVMe 无缓盘，或 4TB+ 机械盘（噪音和速度能接受的话）。
- NAS / 监控盘：选专门的 NAS 盘（如希捷酷狼 / 西数红盘），普通桌面盘扛不住 7×24 小时。

## 一页纸选购清单

1. **定用途**：游戏？干活？还是都要？按上表分配预算。
2. **定 CPU**：选近一两代的甜点型号，据此确定主板平台（AM5 / LGA1851）。
3. **定显卡**：不打游戏跳过；打游戏按显示器分辨率选档；跑 AI 只选 N 卡大显存。
4. **定内存**：32GB DDR5-6000 两根套条，是当下最稳的选择。
5. **定硬盘**：1TB NVMe PCIe 4.0 起步，仓库数据另配大容量盘。
6. **别忘配套**：电源功率留 30% 余量、散热压得住 CPU、机箱装得下显卡——这三个「配角」选错，主角再强也白搭。
