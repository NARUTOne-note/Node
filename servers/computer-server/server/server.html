服务器组成架构

一台物理服务器 = 硬件 + 虚拟化，对外拆出多个虚拟机

从硬件层（CPU/GPU/内存/硬盘/芯片）到虚拟化层（Hypervisor/虚拟机）的全景视图

服务器是什么

  • • 一台为别人提供服务的计算机
  • • 硬件组成和个人 PC 相似
  • • 更强调性能、稳定、散热、安全
  • • 装在机房，7×24 不间断运行
  • • 上面跑 Linux / Windows Server

常见分类

  • • 机架式（Rack）：1U/2U，最常见
  • • 塔式（Tower）：长得像台式机
  • • 刀片式（Blade）：高密度模块化
  • • 按用途：Web/数据库/文件/AI GPU
  • • 按形态：物理机 / 虚拟机 / 云

虚拟机是什么角色

  • • 软件模拟出来的一台"假电脑"
  • • Hypervisor 把真实硬件切成多份
  • • 一台物理机可跑几十台虚拟机
  • • 互不干扰、可随时复制迁移
  • • 用低成本换来资源共享与隔离
