# 名词解释

## 1、Bucket

- 云计算/编程（最常见的技术语境）
- 在开发中，几乎特指对象存储（如 AWS S3、阿里云 OSS、腾讯云 COS 中的“存储桶”）。它本质上是云端用来存放文件（图片、视频、备份等）的“容器”。
- 如果你在配代码或看报错，通常需要关注：Bucket 名称、权限设置（公开/私有） 和 Region（地域）。

## 2、MinIO（JuiceFS S3 网关）

是 JuiceFS 提供的一种访问方式，它本质上是一个将 JuiceFS 分布式文件系统通过标准 S3 协议对外暴露的服务。它的核心价值在于，让原本只支持 POSIX（文件系统）接口的 JuiceFS，也能像兼容 S3 的对象存储一样被访问。
